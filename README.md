# EUDR Due Diligence Costs Calculator

This application calculates the budget for establishing and maintaining an EU Deforestation Regulation (EUDR) due diligence system for operators and traders, including SMEs, based on various factors.

## Requirements

- Python 3.11 or later
- Packages listed in `requirements.txt` (Streamlit, pandas, Plotly)

## Installation

```
pip install -r requirements.txt
```

## Running the app

```
streamlit run calculator.py
```

The app opens in your browser at http://localhost:8501.

## Cost types

- **SET UP COSTS**: one-off effort to establish the due diligence system.
- **ON-GOING COSTS**: recurring effort to operate the system each year.
- **BOTH COSTS**: set-up and on-going costs shown together.
